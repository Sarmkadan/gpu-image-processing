# TransformTypes

The `TransformType` enumeration represents the types of image transformations supported by the GPU image processing pipeline.

## API

### Rotate
Rotation transformation.

### Resize
Resize/scale transformation.

### ColorSpace
Color space conversion.

### Normalize
Normalize pixel values.

### FlipHorizontal
Flip horizontally.

### FlipVertical
Flip vertically.

### Crop
Crop image region.

### Brightness
Brightness adjustment.

### Contrast
Contrast adjustment.

### Gamma
Gamma correction.

### HistogramEqualize
Histogram equalization.

### Perspective
Perspective transformation.
