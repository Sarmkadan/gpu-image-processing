# FilterTypes

The `FilterType` enumeration represents the supported image filter types in the GPU image processing library.

## API

### Gaussian
Gaussian blur filter for smoothing images.

### Bilateral
Bilateral filter for edge-preserving smoothing.

### Median
Median filter for noise reduction.

### Threshold
Threshold filter for binary conversion.

### Sobel
Sobel edge detection filter.

### Canny
Canny edge detection filter.

### MorphOpen
Morphological opening operation.

### MorphClose
Morphological closing operation.

### Laplacian
Laplacian filter for edge detection.

### Custom
Custom user-defined filter.

### Sharpen
Sharpen filter to enhance image details.

### UnsharpMask
Unsharp mask filter for sharpening images by subtracting a blurred version.
